⚡ Fluxo de Eventos em Tempo Real (SSE Data Flow)
1
Telemetria GPS enviada pelo Publisher
Simulador realiza POST HTTP para /telemetry no Backend API.
2
Publicação no Redis Pub/Sub
Backend processa o use case ReceiveTelemetry e publica no canal Redis car-movements.
3
Streaming SSE para o Frontend
Controller do SSE escuta o Redis e transmite via GET /stream (evento: carMoved).
4
Fila de Auditoria de Entregas (AMQP)
Mudanças de status geram eventos na fila RabbitMQ audit.order-status consumidos pelo serviço Audit.

💡 SSE vs WebSockets
• SSE: Unidirecional (Servidor → Cliente), HTTP/1.1 nativo, auto-reconexão no EventSource.
• Ideal para: Dashboards, rastreamento GPS, logs e notificações ao vivo.
